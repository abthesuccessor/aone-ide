# Agent setup

This renderer feature is the single Project Agent surface for readiness, an
approval plan, and engineering chat. It restores an already approved report
for the active workspace without inspecting again; only the explicit inspection
buttons can start native discovery. Every AI question has separate provider
consent and does not add process or filesystem authority.

`model.ts` is the action firewall: only an exact run-profile ID already
registered by Aone can become an approvable IDE-selection action. Missing
tools, environment hints, Docker, and every other recommendation remain manual
engineer steps. AI-generated prose is display-only and never enters the plan
builder or a process argument.

The panel resets on workspace ID or generation changes and ignores stale
inspection and chat results. Its setup, environment, dependency, Docker, run,
and debug prompts are guidance lanes over the bounded report, not executable
skills. Native dialogs remain authoritative for filesystem inspection, version
probes, and provider transmission.
