# UI primitives

Small local wrappers for narrowly selected third-party interaction primitives.
`Resizable.tsx` adapts `react-resizable-panels` to Aone's panel, group, and
accessible handle API; visual behavior remains in `src/styles/resizable.css`.

`button.tsx`, `toggle.tsx`, and `toggle-group.tsx` adapt shadcn's `base-nova`
registry components. Preserve the [upstream MIT notice](../../../docs/licenses/shadcn-MIT.txt)
with source and bundled distributions. The [provenance review](../../../docs/THIRD_PARTY_REVIEW.md)
records the compared sources and other attribution work still to complete.
